Question: List the appropriate HTML input types you would use for each of the five fields. Explain
how you would use HTML5 built-in validation attributes to enforce the two constraints mentioned,
and why these attributes alone are not sufficient for production-level validation.

Answer:

The appropriate HTML input types depend on the five fields in the form. For example:

1. Name: type="text" – To enter the user's name.

2. Email: type="email" – To enter a valid email address.

3. Phone Number: type="tel" – To enter a phone number.

4. Password: type="password" – To enter a password securely on the screen.

5. Age: type="number" – To enter a numeric age.


HTML5 validation attributes:

=> required – Makes a field compulsory.

=> minlength and maxlength – Set the minimum and maximum number of characters.

=> min and max – Set the minimum and maximum allowed numeric values.

=> pattern – Checks whether the input matches a specified format.


These attributes can be used to enforce the form's required constraints. However, HTML5 validation 
alone is not sufficient for production-level validation because users can bypass browser validation. The 
server must also validate the submitted data to protect against invalid or harmful input.
